# 📘 Сопровождающая документация проекта

## 🔗 Доступ к приложению

Чтобы открыть сайт, перейдите по ссылке:
👉 [https://projectconfiguration.onrender.com/](https://projectconfiguration.onrender.com/)

---

## 🔐 Аутентификация

### Вход

На главной странице отображается форма входа, где необходимо ввести:

* имя пользователя
* пароль

### Регистрация

Если у вас нет аккаунта:

1. Нажмите кнопку **«Регистрация»**
2. Заполните форму:

   * имя пользователя
   * email (обязательно на английском)
   * пароль
   * роль (студент / преподаватель / администратор)

После регистрации:

* данные сохраняются в базе данных
* пароль шифруется с использованием `bcrypt`
* происходит редирект на страницу входа

---

## 👤 Роли пользователей и функционал

---

### 🛠 Администратор

После входа доступны следующие функции:

* 📄 Просмотр данных в формате JSON:

  * пользователи
  * мероприятия
  * достижения

* 📊 Таблицы:

  * таблица пользователей
  * таблица мероприятий
  * таблица достижений

* ⚙️ Настройки:

  * переход на страницу настроек
  * (в будущем) изменение пароля
  * выход из аккаунта

📌 *Планируется*: добавление загрузки JSON-файлов

---

### 🎓 Преподаватель

Доступные функции:

* 📅 Просмотреть все мероприятия
* ➕ Добавить мероприятие
* ⚙️ Настройки (аналогично администратору)

#### Добавление мероприятия

Необходимо заполнить:

* название
* описание
* дата проведения
* тип мероприятия

После отправки данные сохраняются в базе данных.

---

### 🎒 Студент

Доступные функции:

* 🏆 Просмотреть свои достижения
* ➕ Добавить достижение
* ⚙️ Настройки (аналогично другим ролям)

#### Просмотр достижений

* данные фильтруются по ID студента
* отображаются в формате JSON

#### Добавление достижения

Необходимо указать:

* название достижения
* категория
* результат
* ссылка на подтверждающий документ (URL)

После отправки данные сохраняются в базе данных.

---

## 🗄 Технические особенности

* Данные хранятся в Postgres базе данных на хостинге Render
* Пароли пользователей шифруются с помощью `bcrypt`
* Доступ к функциям зависит от роли пользователя
* Используется фреймворк FastAPI
